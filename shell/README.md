# Mobile Shell

The Linux-Touch shell is the mobile-first graphical session.

The first implementation will use Qt/QML and Wayland. It should remain independent of individual phone models and communicate with hardware through the project hardware abstraction layer.

## v0.1

The shell only needs to prove that the graphical stack can start automatically in the virtual-phone target.

Planned later components:

- launcher
- status bar
- notifications
- quick settings
- lock screen
- navigation gestures
- settings
- virtual keyboard integration
