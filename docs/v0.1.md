# v0.1 — Foundation / Virtual Phone

## Goal

Boot a reproducible ARM64 Linux system in QEMU using a virtual smartphone target and launch a minimal touchscreen-oriented graphical session.

## In scope

- ARM64 Linux kernel
- Minimal root filesystem
- systemd
- QEMU
- Wayland
- compositor/session
- Qt/QML shell prototype
- virtual-phone device profile
- build and run scripts
- basic automated boot checks

## Out of scope

- Physical phone flashing
- Android APK compatibility
- Cellular modem
- Camera
- Fingerprint reader
- Production GPU support
- OTA updates
- App store
- Custom package manager

## Definition of Done

- [ ] Kernel builds for AArch64.
- [ ] Root filesystem is reproducibly generated.
- [ ] QEMU boots the system without manual commands inside the guest.
- [ ] systemd reaches the expected target.
- [ ] Wayland session starts.
- [ ] The shell starts automatically.
- [ ] A 1080x2400 portrait virtual-phone profile is selectable.
- [ ] Touch input is available to the graphical session.
- [ ] `./scripts/build.sh virtual-phone` performs the build entry point.
- [ ] `./scripts/run.sh virtual-phone` starts the virtual target.

## Architecture

```text
Host Linux
   |
   +-- build tools
   |
   +-- AArch64 kernel
   |
   +-- ARM64 rootfs
   |
   +-- QEMU
          |
          +-- Linux kernel
          +-- systemd
          +-- Wayland
          +-- compositor
          +-- Qt/QML Mobile Shell
```

The device profile is deliberately separate from the OS core. Later physical devices should provide their own kernel, Device Tree, firmware and hardware capabilities without requiring the mobile shell to know the underlying SoC.
